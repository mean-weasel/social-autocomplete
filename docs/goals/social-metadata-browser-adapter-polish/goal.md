- Use only the user’s existing visible Chrome profile for authenticated work.
- Never store or request credentials, profile paths, cookies, tokens, identities, full tab lists, URLs, DOM/body/feed content, or screenshots.
- Filter the intended target inside one bounded operation and return sanitized structural outcomes only.
- Do not publish, open or type into a composer, scrape/crawl, bypass challenges, or broaden reads to force a pass.
- Keep `ui_change`, authentication, challenge, locale mismatch, and native empty distinct.
- Autocomplete order is not popularity or performance proof.
- Every recommendation requires exact fresh channel-native autocomplete evidence.
- Preserve the stable CLI/JSON contract and manager-owned recovery protocol.
- Keep Claude-host testing and CI design outside this tranche.
- Do not publish the currently empty GitHub repository without explicit owner approval.
